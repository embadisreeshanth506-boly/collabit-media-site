Neon Rush Privacy Policy

Draft updated: 25 October 2026 · Operator: Collabit Media

About the game

Neon Rush is an obstacle-running game operated by Collabit Media. The developer describes the intended audience as ages 8 and above.

Local saves and accounts

Neon Rush has no login system or player accounts. Game save data is stored locally on the player’s device. The developer reports no direct collection of personal details.

Analytics

Neon Rush does not include a Firebase or Google Analytics SDK. There is no Analytics retention period to report. This corrects an earlier version of this draft that described Google Analytics usage tracking. Advertising services are separate and may process data as described below.

Advertising

Neon Rush uses Google AdMob through the Poing Godot AdMob plugin for banner, interstitial, and rewarded advertisements. Google’s Mobile Ads SDK documentation describes collection and sharing of IP addresses, interaction data, diagnostics, and device or account identifiers for advertising, measurement, and fraud prevention. The exact SDK version and configuration in the released game must be checked against that documentation before the final Data safety declaration. Advertising-provider retention and deletion practices still require verification. See the Google Privacy Policy.

Retention and deletion

Local game save data remains on your device until you remove it. To delete it, clear Neon Rush’s app storage in your device settings or uninstall the app. The game does not have an in-app delete button.

Clearing storage or uninstalling deletes local app data; it does not constitute a deletion request for information already processed by advertising providers. For formal privacy or deletion enquiries, contact collabitmedia@gmail.com. Provider-specific deletion options and retention details still need verification.

Children and advertising settings

The developer describes the intended audience as ages 8 and above. The current ad configuration has a maximum ad content rating of PG, child-directed treatment is not enabled, and the under-age-of-consent flag is false. The developer confirms that ads are not yet configured as child-directed or non-personalized for this audience.

These settings must be reconciled with the intended audience before the game and this policy are ready for the Play listing. A PG ad content limit alone does not establish child-directed treatment.

Advertising privacy choices

The supplied wrapper includes Google’s User Messaging Platform consent flow and a function for opening privacy options. Whether players can access that function from the game interface has not yet been verified. Consent-error handling currently needs correction before ad requests can be reliably gated on permission to request ads.

Security

Game saves are held locally on the device. Specific storage protections and advertising SDK security practices have not yet been verified; this draft makes no claim of encryption or other unconfirmed safeguards.
